## ✨ תכונות עיקריות

- **שרטוט רשת תאורה אינטראקטיבי:** הוספת עמודים, נקודות ניתוב וקווים על גבי משטח עבודה מתקדם.
- **טעינת תוכניות ורקעים:** תמיכה בקבצי תמונה ו-PDF כרקע לשרטוט, כולל כיול קנה מידה.
- **חישוב מפלי מתח אוטומטי:** חישוב עומסים, מפל מתח וזרמים לאורך הקווים והמעגלים.
- **ייבוא וייצוא מלא:** שמירת פרויקטים בפורמט JSON קל משקל וטעינתם מחדש בכל עת.
- **ניידות מקסימלית:** קובץ HTML יחיד שניתן להעביר בדיסק-און-קי, לשתף במייל או להריץ ברשת ללא שום תלות בשרת או בהתקנות נוספות.
