# Lighting Network Planner - מתכנן רשת תאורה 💡

אפליקציית Web עצמאית וקלת משקל לתכנון, שרטוט וחישוב רשתות תאורה ומפלי מתח.

---

## 🚀 הפעלה מיידית (איך מפעילים?)

האפליקציה אינה דורשת התקנה כלל!
1. פשוט לחץ לחיצה כפולה (Double Click) על הקובץ **`מתכנן רשת תאורה.html`**.
2. האפליקציה תיפתח מיידית בדפדפן המועדף עליך (Google Chrome, Microsoft Edge וכו').

---

## ✨ תכונות עיקריות

- **שרטוט רשת תאורה אינטראקטיבי:** הוספת עמודים, נקודות ניתוב וקווים על גבי משטח עבודה מתקדם.
- **טעינת תוכניות ורקעים:** תמיכה בקבצי תמונה ו-PDF כרקע לשרטוט, כולל כיול קנה מידה.
- **חישוב מפלי מתח אוטומטי:** חישוב עומסים, מפל מתח וזרמים לאורך הקווים והמעגלים.
- **ייבוא וייצוא מלא:** שמירת פרויקטים בפורמט JSON קל משקל וטעינתם מחדש בכל עת.
- **ניידות מקסימלית:** קובץ HTML יחיד שניתן להעביר בדיסק-און-קי, לשתף במייל או להריץ ברשת ללא שום תלות בשרת או בהתקנות נוספות.

---

## 🌐 הפעלה דרך GitHub Pages

ניתן להפעיל את האפליקציה כאתר אינטרנט חי בחינם:
1. היכנס להגדרות הריפוזיטורי ב-GitHub: **Settings -> Pages**.
2. בחר תחת **Branch** את הענף `main` ושמור (**Save**).
3. האפליקציה תהיה זמינה לשימוש מכל דפדפן ומכל מכשיר דרך הקישור הישיר של ה-Pages.
